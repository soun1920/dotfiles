# 原文と訳文の引用

引用と執筆者の説明を分け、原文と訳文を照合できるようにする。これは引用の書式であり、全文引用や引用量を指定する規則ではない。

- 原文をフェンス付きコードブロックへ入れる。Markdown の > による引用は使わない。
- 原文が文書と別の言語なら、同じブロック内に空行を一つ挟んで訳文を置く。同じ言語なら訳文は不要。
- 出典は閉じフェンス直後の独立した行へ置く。引用文や訳文の中へ混ぜない。
- 出典には資料名・年・位置を使う。対象論文の解説では [p.X, Section Y] を使う。番号だけの参照にしない。
- 省略箇所を明示する。元資料にない文、別の節からの文、自分の補足を一続きの原文引用にしない。
- 引用の上限や利用条件を優先する。長い内容は自分の言葉で説明し、参照位置を残す。
- HTML の引用には html skill の引用コンポーネントを使い、原文・訳文・出典の区別を維持する。

書式例（以下の原文・訳文は自作）:

```text
The input is a sequence of bytes.

入力はバイト列です。
```
