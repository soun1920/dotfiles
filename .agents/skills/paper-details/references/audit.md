# 詳細解説の監査

解説と原論文を節ごとに照合する。監査ファイルが存在するだけでは監査を実施した証拠にならない。

- 確認対象は主要な主張・省略、引用位置、訳文、数式・記号、図表・数値、外部文献との対応、用語の一貫性とする。
- 分担が許可されている場合は、独立して比較できる節をサブエージェントへ渡してよい。原論文、対象節、確認基準、出力先を渡し、解説本体は同時編集させない。
- 使用可能な同時実行数に収まる件数で進める。一節につき一人を一斉起動する必要はない。分担できなければ主担当が照合し、その方法を記録する。
- 独立監査を明示的に求められたのに実施できない場合は、自己点検で代替したことを明示し、独立監査は未実施とする。
- 結果は既存の保存先に従い、なければプロジェクトの subagent-reviews/ に節別または関連する節をまとめて保存する。担当・確認方法、総合評価、位置付きの指摘、修正案を記録する。主担当の確認をサブエージェントの監査と偽らない。
- 指摘は原典へ戻って確認する。監査者間の食い違いを多数決で決めない。
- 確認できた指摘を反映し、変更箇所と共通する用語・参照を再確認する。未解決があれば何が残るかを報告する。
