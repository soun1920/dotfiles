# 図表の抽出

既存スクリプトは SKILL.md と同じディレクトリの scripts/extract_images.py にある。実行前に使用環境と依存を確認する。

```sh
uv run /path/to/paper-details/scripts/extract_images.py /path/to/paper.pdf
```

- 原典の図表一覧とキャプション表記を先に確認する。既存スクリプトは Figure N / Table N を想定するため、Fig.、TABLE、ローマ数字などでは取りこぼすことがある。
- 抽出が0件でも図表がないと結論しない。PDF の該当ページと描画領域を確認する。解像度を上げてもキャプションの検出漏れは直らない。
- 自動抽出に失敗した項目は、利用可能な PDF レンダラーで該当領域を切り出す。新しい表や模倣図へ書き直さない。
- 出力はプロジェクトの images-from-papers/ にまとめ、論文名と図表番号で区別する。複数パネルの図表は原典の単位を保つ。
- 生成画像を開き、本文の混入、切れ、欠落、可読性を確認する。manifest があれば件数・パスも照合する。
- Markdown では成果物からの相対パスで画像を参照する。訳したキャプションは画像の下に置き、画像内の原文は書き換えない。
