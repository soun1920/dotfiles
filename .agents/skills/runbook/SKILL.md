# 実行手順書

依頼された操作をユーザーが再現できる、短い番号付きの手順にする。

- 先に確認できる環境・状態を調べる。承認済みで実行可能な操作まで、sudo や GUI という語だけを理由に差し戻さない。
- ユーザーが手順書を求めた場合は、対象システムを変更する操作を実行しない。途中で本人の操作が必要になった場合は、その操作だけを手順書にする。
- 各手順には、実行環境と場所、コピーできるコマンドまたは画面操作、期待する結果、違った場合の確認方法を書く。
- 不可逆な操作は対象と影響を具体的に示す。認証情報をコマンドや回答へ貼り付けさせない。
- 観測済みの出力と、これから期待する出力を区別する。環境名などの置換箇所は明示する。
- ユーザーの結果が必要な後続処理だけを待つ。独立して進められる依頼内の作業は継続する。
