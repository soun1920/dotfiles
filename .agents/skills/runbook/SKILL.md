# 手順書を渡す

- 読み取り専用のコマンドで先に診断する。sudo や対話入力が要るコマンドは実行しない。
- 手順は番号付きで、1手順につき「コマンド」「期待する出力」「違ったときの対処」の3点を書く。
- コマンドはそのまま貼れる形にする。置き換える箇所は `<name>` で囲む。
- 各手順に実行環境を明記する。ホストか、distrobox のどのコンテナか、Flatpak か。
- 手順書を渡したら、ユーザーが実行して結果を貼るのを待つ。結果を見てから次の診断に進む。
