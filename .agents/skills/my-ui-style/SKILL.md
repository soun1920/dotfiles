# UI の既定スタイル

新規 UI で別の指定がない場合、Material Design 3（M3）のトークンと部品の仕様を使い、水色（種色 `#4FC3F7`）から生成した配色にする。

## 適用範囲

- 既存 UI の修正では、そのプロジェクトのデザインと部品を使う。見た目と関係しない変更で配色やフォントを変えない。
- html skill の説明文書は専用の document.css を使う。M3 の配色へ変更せず、専用文書の配色・用語欄・図の規則を優先する。
- ユーザー指定の見本やブランドがある場合はそちらを優先する。
- これは個人のデザイン規約である。M3 への準拠やアクセシビリティ適合を、スタイルの適用だけで保証したと報告しない。

## 共通の要点

- 新規 UI の既定はダーク。色は M3 の役割名のトークン（`--md-sys-color-*`）だけを参照し、面と文字は対（surface と on-surface など）で使う。
- 背景の階層は surface container の段階で表し、影はメニュー・FAB・ダイアログなど浮く部品に限る。hover・focus・押下は状態レイヤーで表す。
- 見出しは Zen Maru Gothic、本文は Zen Kaku Gothic New、コードは Noto Sans Mono を基本とし、既存のフォント設定があれば尊重する。M3 の型の段階は使うが、文字は 14px 以上にする。
- ネイティブの入力部品、ラベル、キーボード操作、見えるフォーカス、動きを減らす設定を維持する。意味を伝える色は文字や形状と組み合わせる。
- トークンや部品を新しく作るときは [詳細ガイド](references/design-guide.md) の該当節を参照する。色は2節、文字は3節、配置は4〜7節、状態とフォーカスは8節、部品は9節、操作性とモーションは10〜11節が該当する。CSS/JSX の例を使うためだけに新しい依存（Material Web など）を追加しない。
- 変更後は対象画面で確認する。確認できていない表示や操作を、コードの検査だけで成功扱いにしない。
