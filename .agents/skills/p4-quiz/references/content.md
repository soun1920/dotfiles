## 第1回：文字列

### 重要概念

**文字とコード**
- 1文字 = 8bit（ASCIIの範囲）
- char型で1文字を扱う
- 文字列 = char型の配列
- 末尾には必ず終端文字 `'\0'`（ヌル文字）が入る
- 大文字と小文字の差は10進数で **32**（例：`'A'=65`，`'a'=97`）

**文字コード早見**
- `'A'` = 65，`'a'` = 97
- `'0'` = 48
- `'I'` = 73，`'1'` = 49

**文字列の入出力**
```c
char s[1024];
scanf("%s", s);
printf("%s\n", s);
```

**文字列ループのイディオム**
```c
for (i = 0; s[i] != '\0'; i++) { ... }
```

### 標準ライブラリ（授業では自作する）
- `strlen(s)` : 文字数を返す
- `strcpy(s, t)` : t を s にコピー
- `strcmp(s, t)` : 比較（同じなら0，ただし授業では1を返す自作版）
- `strcat(s, t)` : s の末尾に t を連結
- `toupper(c)` / `tolower(c)` : 大文字・小文字変換

### 典型問題と解答

**Q1: myStrlen の実装**
```c
int myStrlen(char s[]) {
    int i;
    for (i = 0; s[i] != '\0'; i++);
    return i;
}
```

**Q2: 大文字に変換する myToUpper**
```c
void myToUpper(char s[]) {
    int i;
    for (i = 0; s[i] != '\0'; i++) {
        if ('a' <= s[i] && s[i] <= 'z')
            s[i] = s[i] - 32;
    }
}
```

**Q3: 書き間違い修正（課題1）**
'1' を 'I' に書き換える
```c
for (i = 0; s[i] != '\0'; i++) {
    if (s[i] == '1') s[i] = 'I';
}
```

**Q4: ゆるい文字列比較 fuzzyStrcmp（課題2）**
大文字小文字を区別しない比較

**Q5: 回文判定 isPalindrome（課題3）**
先頭と末尾から比較していき，全て一致すれば回文

## 第2回：動的メモリ管理

### 重要概念

**静的 vs 動的領域**
- 静的：プログラム実行前に確保（`int a[100];`）
- 動的：実行中に確保・解放（malloc/free）

**malloc の使い方**
```c
#include <stdlib.h>
int *a;
a = (int *)malloc(sizeof(int) * n);
if (a == NULL) { printf("ERROR\n"); return 0; }
// 使い終わったら
free(a);
```

**sizeof の返り値**
- `sizeof(int)` = 4
- `sizeof(int *)` = 8（64bit環境）
- `sizeof(char)` = 1

**2次元配列の動的確保（ダブルポインタ）**
```c
int **mat;
mat = (int **)malloc(sizeof(int *) * a);  // 行のポインタ配列
for (i = 0; i < a; i++) {
    mat[i] = (int *)malloc(sizeof(int) * b);  // 各行のデータ
}
```

### よくある間違い
```c
// 間違い（int* サイズではなく int サイズを確保してしまう）
mat = (int **)malloc(sizeof(int) * a * b);

// 正しい
mat = (int **)malloc(sizeof(int *) * a);
```

### 典型問題

**Q1: 1次元動的確保**
n個のint配列を動的確保し，1〜nを代入して出力

**Q2: 2次元動的確保（課題1）**
a×b の行列を動的確保，[0][0]から順に1,2,3,...を代入

**Q3: 文字列の動的確保（setPalindrome, 課題2）**
- バッファーで受け取り → 文字数を数える → malloc → コピー

## 第3回：線形探索と二分探索

### 重要概念

**線形探索 O(n)**
- 先頭から順番に1つずつ見ていく
- ソート済みでなくても使える
- 最悪 n 回の比較

```c
int linear_search(int a[], int n, int x) {
    int i, ret = -1;
    for (i = 0; i < n; i++) {
        if (a[i] == x) { ret = i; break; }
    }
    return ret;
}
```

**二分探索 O(log n)**
- 必ず**昇順ソート済み**の配列に使う
- lef（先頭），rig（末尾），mid（中間）を使う

```c
int binary_search(int a[], int n, int x) {
    int lef = 0, rig = n - 1, mid;
    while (lef <= rig) {
        mid = (lef + rig) / 2;
        if (a[mid] == x) return mid;
        else if (x < a[mid]) rig = mid - 1;
        else lef = mid + 1;
    }
    return -1;
}
```

**二分探索のトレース例（x=34，配列: 1 2 3 4 5 8 9 13 16 21 25 27 32 34 36 49...）**
1. lef=0, rig=20, mid=10 → a[10]=25 < 34 → lef=11
2. lef=11, rig=20, mid=15 → a[15]=49 > 34 → rig=14
3. lef=11, rig=14, mid=12 → a[12]=32 < 34 → lef=13
4. lef=13, rig=14, mid=13 → a[13]=34 == 34 → return 13

**オーダーの種類**
| 記法 | 意味 | 例 |
|------|------|-----|
| O(1) | 定数 | 配列の添え字アクセス |
| O(log n) | 対数 | 二分探索 |
| O(n) | 線形 | 線形探索，配列の合計 |
| O(n log n) | 線形×対数 | マージソート，クイックソート平均 |
| O(n²) | 二乗 | バブルソート，選択ソート，挿入ソート |

## 第4回：ソートアルゴリズム

### バブルソート
- 隣り合う要素を比較して順序が逆なら交換
- 1パスで最大値が末尾に移動（泡が浮かぶイメージ）
- 時間計算量：O(n²)，空間計算量：O(n)
- 実装が最もシンプル

```c
void BubbleSort(int a[], int n) {
    int i, j;
    for (i = 0; i < n - 1; i++) {
        for (j = 1; j < n - i; j++) {
            if (a[j-1] > a[j]) swap(&a[j-1], &a[j]);
        }
    }
}
```

### 選択ソート（単純選択ソート）
- 未整列部分から最小値を選んで先頭と交換
- 時間計算量：O(n²)，空間計算量：O(n)

### 挿入ソート（単純挿入ソート）
- 未整列部分の先頭を取り出し，整列済み部分の適切な位置に挿入
- 時間計算量：O(n²)，空間計算量：O(n)
- **ほぼ整列済みのデータに対して高速**

### バケットソート
- データが取りうる範囲の配列を用意して数える
- 時間計算量：O(n)（データの範囲が小さい場合），空間計算量：O(最大値)
- 整数でないと使いにくい

### マージソート
- 分割と併合の2フェーズ
- 時間計算量：O(n log n)，空間計算量：O(n log n)（工夫でO(n)）
- 安定ソート

### クイックソート
- ピボットを基準に左右に分割，再帰
- 平均時間計算量：O(n log n)，最悪：O(n²)
- 空間計算量：O(n)
- 実際には最も速いことが多い

### 比較表
| ソート | 平均時間 | 最悪時間 | 空間 | 特徴 |
|--------|---------|---------|------|------|
| バブル | O(n²) | O(n²) | O(n) | 実装簡単 |
| 選択 | O(n²) | O(n²) | O(n) | - |
| 挿入 | O(n²) | O(n²) | O(n) | ほぼ整列済みに高速 |
| バケット | O(n) | O(n) | O(最大値) | 整数限定 |
| マージ | O(n log n) | O(n log n) | O(n) | 安定 |
| クイック | O(n log n) | O(n²) | O(n) | 実用最速 |

## 第5回：リスト構造（線形リスト）

### 重要概念

**ノードの構造体**
```c
typedef struct node {
    int val;
    struct node *next;
} Node;
```

**グローバル変数**
```c
Node *head = NULL;
```

### 主な関数とアルゴリズム

**ノード生成**
```c
Node* createN(int x) {
    Node *newnode = (Node *)malloc(sizeof(Node));
    newnode->val = x;
    newnode->next = NULL;
    return newnode;
}
```

**先頭への挿入 O(1)**
```c
void insHead(int x) {
    Node *p = createN(x);
    p->next = head;
    head = p;
}
```

**末尾への挿入 O(n)**
末尾まで辿ってから `p->next = createN(x);`

**先頭の削除 O(1)**
```c
void delHead() {
    Node *p = head;
    head = head->next;
    free(p);
}
```

**リスト出力**
```c
void printL() {
    Node *p = head;
    while (p != NULL) {
        printf("%d ", p->val);
        p = p->next;
    }
    printf("\n");
}
```

**要素検索 searchX**
headから辿り，値が一致したらそのノードを返す（見つからなければNULL）

### 配列 vs 線形リスト
| 操作 | 配列 | 線形リスト |
|------|------|----------|
| 生成 | 静的（固定） | 動的（可変） |
| 先頭挿入 | O(n) | **O(1)** |
| 末尾挿入 | O(1) | O(n) ※末尾ポインタで O(1) も可 |
| 先頭削除 | O(n) | **O(1)** |
| n番目アクセス | **O(1)** | O(n) |
| 二分探索 | 可能 | 不可（線形探索のみ） |

## 第6回：木構造・二分木

### 木構造の用語
- **根（root）**：親を持たないノード
- **葉（leaf）**：子を持たないノード
- **深さ**：根からの距離
- **高さ**：木全体の最大深さ

### 二分木の種類
- **二分木**：子が0〜2
- **完全二分木（ゆるい定義）**：最深層以外が埋まっており，最深層は左から詰まっている
- **二分探索木（BST）**：左の子 < 親 < 右の子

### 配列による二分木の実装
- 根 = `t[1]`，空ノードは `t[i] = -1`
- 左の子：`i * 2`
- 右の子：`i * 2 + 1`
- 親：`i / 2`

### 二分探索木への挿入
根から辿り，x > t[i] なら右，x < t[i] なら左へ，-1 の場所に挿入

### 木の巡回（traversal）
```c
// 中間順（inorder）: 左 → 根 → 右 → 昇順になる
void inOrder(int i) {
    if (t[i] == -1) return;
    inOrder(goL(i));
    printf("%d ", t[i]);
    inOrder(goR(i));
}

// 先行順（preorder）: 根 → 左 → 右
void preOrder(int i) {
    if (t[i] == -1) return;
    printf("%d ", t[i]);
    preOrder(goL(i));
    preOrder(goR(i));
}

// 後行順（postorder）: 左 → 右 → 根
void postOrder(int i) {
    if (t[i] == -1) return;
    postOrder(goL(i));
    postOrder(goR(i));
    printf("%d ", t[i]);
}
```

### ヒープ木（最大ヒープ）
- **条件**：常に親 ≥ 子（根が最大値）
- **完全二分木（ゆるい定義）**に配置

**アップヒープ（追加）**：末尾に追加 → 親と比較して親より大きければ交換，を繰り返す

**ダウンヒープ（取り出し）**：根を取り出し → 末尾の要素を根に移す → 子の中で最大のものと比較して子が大きければ交換，を繰り返す

### ヒープ木 vs 二分探索木
| 比較 | ヒープ木 | 二分探索木 |
|------|---------|----------|
| 木の種類 | 緩い完全二分木 | 二分木 |
| 順序 | 緩い（親≥子） | 完全（左<親<右） |
| 探索 | O(n)（全探索） | O(log n)（平均） |
| 追加・削除 | O(log n) | O(log n)（平均） |

### 優先度付きキュー
- **追加**：アップヒープで O(log n)
- **最大値取り出し**：ダウンヒープで O(log n)
- 応用：経路探索，データ圧縮（ハフマン符号化），ヒープソート
