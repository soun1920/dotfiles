# プログラミング４ 問題出題スキル

## 概要

このスキルは，工学院大学プログラミング４（前山和喜 担当）の全6回分のスライドをもとに，ユーザーに問題を出題・採点するためのスキルです。

---

## 出題フロー

1. ユーザーが対象回・形式・難易度を指定（または指定がなければ聞く）
2. `references/content.md` を参照して該当回のコンテンツを確認する
3. 問題を生成して出題する
4. ユーザーの解答を受け取る
5. 採点・解説をする
6. 次の問題を出すか確認する

---

## 対象回と内容

| 回 | テーマ | 主なキーワード |
|----|--------|---------------|
| 第1回 | 文字列 | char型，ASCIIコード，終端文字\\0，strlen/strcpy/strcmp/strcat，大文字小文字変換 |
| 第2回 | 動的メモリ管理 | malloc，free，sizeof，ダブルポインタ，静的/動的領域 |
| 第3回 | 線形探索・二分探索 | linear_search，binary_search，lef/mid/rig，O(n)，O(log n)，時間計算量 |
| 第4回 | ソートアルゴリズム | バブルソート，選択ソート，挿入ソート，バケットソート，マージソート，クイックソート，O(n^2)，O(n log n) |
| 第5回 | リスト構造 | ノード，head，next，NULL，createN/insertHead/delHead/searchX，配列との比較 |
| 第6回 | 木構造・二分木 | 根/葉/親/子，二分探索木，ヒープ木，完全二分木，アップヒープ/ダウンヒープ，中間順/先行順/後行順巡回，優先度付きキュー |

## 問題の種類

以下の種類を組み合わせて出題する。ユーザーの希望や理解度に合わせて選ぶ。

### A. 知識・用語問題
概念や用語の説明を問う。選択肢形式または記述形式。

例：
- 「終端文字（ヌル文字）を使う目的を説明してください」
- 「バブルソートの平均時間計算量のオーダーは何ですか？」

### B. コード穴埋め問題
C言語のコードの一部を空欄にして埋めさせる。

例：
```c
int myStrlen(char s[]) {
    int i;
    for (i = 0; ____; i++);  // ← ここを埋めよ
    return i;
}
```

### C. トレース問題
アルゴリズムの動作を手で追わせる。

例：
- 「配列 [5, 3, 8, 1, 4] をバブルソート（1パス目）した結果を示せ」
- 「二分探索で x=34 を探すとき，lef/mid/rig がどう変化するか示せ」

### D. 実装問題
関数の仕様を与えて実装させる。（難易度高）

---

## 出題ガイドライン

- **1問ずつ**出題し，ユーザーが解答したら採点・解説を行う
- 解答を受け取る前に答えを言ってはいけない
- 採点後は「正解/不正解/部分点」を明確に示す
- 間違えた場合はヒントを出して再挑戦を促すか，丁寧に解説する
- 連続出題する場合は，前の問題の正誤を踏まえて難易度を調整する
- コード問題では，C言語として文法的に正しいかも確認する
- ユーザーが「スキップ」「分からない」「答えを教えて」と言った場合は，解説を提供してから次へ進む

---

## 難易度の目安

| 難易度 | 内容 |
|--------|------|
| 基礎 | 用語の定義，オーダーの読み方，簡単なトレース |
| 標準 | コード穴埋め，5〜10要素のトレース，アルゴリズムの特徴比較 |
| 応用 | 関数の実装，複数アルゴリズムの比較・選択理由，ヒープ木操作 |
